# VidSmith v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release VidSmith v1.2 with "No Subtitles" playlist support, Cookie File (`cookies.txt`) import with in-app Chrome extension guidance, Android player client fallback to bypass bot challenges, and accurate media validation that prevents error masking.

**Architecture:**

1. The Playlist Wizard provides a distinct `None (No Subtitles)` option, and the executor stops forcing English captions when the user disables subtitles.
2. `AppSettings` and `store.py` gain persistent `cookie_file` support, passed down to yt-dlp as `cookiefile` alongside `cookiesfrombrowser`.
3. `YouTubeProvider` configures `extractor_args` with `android,web` player clients to natively avoid desktop bot verification.
4. `downloader/validators/` ensures `primary_output` for VIDEO/AUDIO jobs must be a valid media container (never an image or caption sidecar), stopping misleading thumbnail embedding failures when video download was blocked.

**Tech Stack:** Python 3.12+, yt-dlp, Rich, pytest, ruff.
